Basic L1
```
program ::=
    | int main() <block>
block ::=
    | { <stmts> }
stmt ::=
    | <decl>;
    | <sasexpr>;
    | return <expr>;
stmts ::=
    | <block>
    | <stmt> <stmts>
decls ::= 
    | int ident;
    | int ident = <expr>;
lvalue ::=
    | ident
    | (<lvalue>)
binops ::= + | - | * | / | %
asnop ::= += | = | -= | /= | *= | %=
/07/ /'
sasexpr ::= <lvalue> <asnop> <expr>
expr ::=
    | (<expr>)
    | ident
    | <expr> <binop> <expr>
    | - <expr>
    
intconst ::=
    | decnum
    | hexnum
```

Precedence
```
-                (right, unary)
* / %            (left)
+ -              (left)
= += -= *= /= %= (right)
```

Single line comments: //
Multi line comments: /* */

Lex Regular Expresssion:
```
<ident> ::= [A-Za-z_][A-Za-z0-9_]*
<num> ::= <decnum> | <hexnum>
<decnum> ::= 0 | [1-9][0-9]*
<hexnum> ::= 0[xX][0-9a-fA-F]+
<unop> ::= -
<binop> ::= + | - | * | / | %
<asnop> ::= = | += | -= | *= | /= | %=
<reserved> ::= --
```

Reserved words:
```
struct typedef if else while for continue break
return assert true false NULL alloc alloc_array
int bool void char string
```

Static semantics
- every variable must be declared and initialized before use (note: every variable need not be used)
- every control flow path must end with `return`

Dynamic semantics
- self-assign exprs are auto expanded. Ex: `x += e` == `x = x + e`
- integers (dec and hex) are 32 bit, twos complement, can never raise overflow exception
- division rounds down to integer, raises exception if divide by zero or out of range
- modulus `i % k` has the same sign as `i`, raises exception if divide by zero or out of range
